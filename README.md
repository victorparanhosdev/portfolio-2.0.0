## 🚀 Funcionalidades

- Modo dark/light com persistência de tema

- Responsividade para todos os tamanhos de tela

- Página /projetos com paginação dos projetos, campo de busca por nome

- Tradução para múltiplos idiomas

- Integração com API do GitHub para exibição dinâmica dos projetos

## 🛠️ Tecnologias Utilizadas

- Tailwind CSS: Estilização moderna e responsiva

- Next.js 14: Estrutura do projeto com App Router

- NextUI: Componente de paginação

- React-icons: Ícones diversos

- Radix UI: Modais, tabs e switch para dark mode

- Framer Motion & AOS: Animações de entrada e transições

- Hamburger-react: Ícone animado do menu mobile

- Next-intl: Tradução e internacionalização 🌍

- Next-themes: Alternância entre dark/light mode

- Swiper: Carrossel de slides responsivo

- React-loader-spinner: Loader customizado

- Use-debounce: Controle de chamadas à API

- Skeletons: Indicadores de carregamento enquanto os dados são buscados

## 💡 Aprendizados

- Este projeto me ajudou a evoluir no estudo e implementação de diversas bibliotecas modernas. Aprimorei minha leitura de documentações técnicas, integração com APIs externas (como a do GitHub) e controle de parâmetros dinâmicos para exibição dos projetos em tempo real no portfólio.



## 🔧 Instalação e Configuração

Pré-requisitos

- Node.js (versão LTS recomendada)

- npm ou yarn

#### Passos para instalação

Clone o repositório:

```
git clone https://github.com/victorparanhosdev/portfolio-2.0.0.git
cd portfolio-2.0.0
```

Instale as dependências:

```
npm install
ou
yarn
```

Inicie a aplicação:

```
npm run dev
ou
yarn dev
```

- A aplicação estará disponível em: http://localhost:3000
